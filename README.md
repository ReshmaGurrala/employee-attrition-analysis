
# Employee Attrition Analysis and Prediction

## 📌 Project Overview

This project analyzes employee attrition using Exploratory Data Analysis (EDA) and Machine Learning techniques. The objective is to identify the key factors influencing employee turnover and build predictive models to support HR decision-making.

---

## 🎯 Objectives

- Analyze employee attrition patterns
- Perform data cleaning and preprocessing
- Explore relationships between employee characteristics and attrition
- Build and compare machine learning models
- Generate business recommendations

---

## 📂 Dataset

- IBM HR Analytics Employee Attrition & Performance Dataset
- Records: **1470**
- Features: **35**
- Target Variable: **Attrition**

## 🤖 Machine Learning Models

## 📈 Evaluation Metrics

- Accuracy Score

- Classification Report

---

## 💡 Key Business Insights

- Employees working overtime are more likely to leave.
- Lower monthly income is associated with higher attrition.
- Job satisfaction has a strong impact on employee retention.
- Attrition varies across departments and job roles.
- Random Forest achieved the best predictive performance.
